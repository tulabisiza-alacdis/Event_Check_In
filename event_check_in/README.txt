EVENT CHECK-IN APP — VS CODE

This is the Event Check-In app from item #23:
"Event Check-in — Check guests in by name or ticket code — School org events — Tulabis, Iza A."

FILES:
- index.html
- style.css
- script.js

HOW TO RUN IN VS CODE:
1. Open the Event_Check_In_App folder in Visual Studio Code.
2. Open index.html.
3. Install/use the Live Server extension if you have it.
4. Right-click index.html -> Open with Live Server.
   OR simply open index.html in Chrome.
5. Test it using:
   - Search "Maria Santos" or "EVT-1001"
   - Search "Angelica Mae Cruz" or "EVT-1003"
   - Click Check In
   - Open Guest List to see the updated status.

The app uses localStorage, so guest records and check-in status remain after refreshing the browser.
No database or Node.js installation is required.
